Entry for the make.fun bounty [The Most Boring Object, Reviewed in One Line](https://make.fun/b/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3?utm_source=github&utm_medium=readme&utm_campaign=most-boring-object-review).

`main.py` writes the review to `/output/entry.txt`:

> The nail clipper trims all ten nails in silence, then fires the last clipping across the room — a bare foot will find it next week and file the report.

The line was picked by duelling fifteen drafts against the competition's
published judge brief and the strongest lines in the live field (247 entries
sampled): the crowded lanes (doorstop, rubber band, the dustpan's last line
of dust) were avoided for an object nobody else reviewed, whose own
behaviour — a perfect silent trim, one escaped clipping, a bare foot a week
later — is the whole joke. The full draft list and duel record are in
[candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
